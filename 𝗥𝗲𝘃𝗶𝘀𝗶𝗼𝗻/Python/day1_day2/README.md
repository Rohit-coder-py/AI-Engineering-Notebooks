# Day 1 & Day 2 — Python Fundamentals (Internship-Interview Ready)

This folder is built for someone **revisiting Python** to deepen concepts and prepare for a first internship interview.
Every file mixes **theory** (as comments/docstrings) with **practical code**, plus **interview-level notes** (memory model, identity, gotchas, PEP 8, etc.).

## How to use
1. Read each `.py` file top-to-bottom — theory first, then code, then interview notes.
2. Run a file: `python day1/01_variables_assignment.py`
3. Experiment: break the code on purpose, then fix it.
4. Attempt the interview questions **without** looking at the answers first.
5. Use `projects/day1_practice.py` and `projects/day2_practice.py` to write your own solutions before checking the project files.
