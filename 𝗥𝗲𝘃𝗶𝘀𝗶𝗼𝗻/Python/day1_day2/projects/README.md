## Workflow for blanks
1. Read the docstring at the top: requirements, data shape, hints.
2. Write the functions (replace `pass`).
3. Uncomment the self-tests at the bottom and run the file.
4. Only then compare with the solved projects' style.

## Interview angle
For each project, be ready to explain: *why this data structure?* (list vs dict vs set), *time complexity of the key operation*, and *what edge cases did you handle* (empty input, duplicates, bad input).

Run solved ones: `python 03_grade_calculator.py`, `python 04_word_frequency_analyzer.py` (no input needed); `01` and `02` are interactive.
