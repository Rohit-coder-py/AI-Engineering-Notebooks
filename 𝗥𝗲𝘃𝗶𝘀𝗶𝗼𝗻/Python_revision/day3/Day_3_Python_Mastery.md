## How to Study Each Topic

Follow the roadmap's learning cycle for every topic:

1. **Understand** — Learn what the concept is, why it exists, when it is useful, and how Python handles it internally where relevant.
2. **Implement** — Write small examples yourself in VS Code. Do not simply copy code.
3. **Explain** — Explain the concept in your own words, as if teaching another person.
4. **Active recall** — Answer questions independently before asking for hints or corrections.
5. **Improve** — Review technical accuracy, clarity, missing details, and interview-ready structure. Rewrite weak answers in your own words.
6. **Practise** — Solve output-prediction, debugging, edge-case, and coding questions.

### When is a topic complete?

A topic is complete only when you can:

- Explain it without reading notes.
- Write a working example independently.
- Predict or reason about its behaviour.
- Identify at least one common mistake or edge case.
- Answer a follow-up interview question.
