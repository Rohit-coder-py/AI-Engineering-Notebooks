# KrishiMitra AI - Streamlit UI

1. Put this `app.py` in your project folder (replace the old one), next to
   `.env` and the `deep_learning_chroma_db` folder.
2. Install: `pip install -r requirements.txt`
3. Run: `streamlit run app.py`

Make sure `.env` contains `GROQ_API_KEY=...`.
The vector DB is NOT included in this zip - keep using your existing one.
