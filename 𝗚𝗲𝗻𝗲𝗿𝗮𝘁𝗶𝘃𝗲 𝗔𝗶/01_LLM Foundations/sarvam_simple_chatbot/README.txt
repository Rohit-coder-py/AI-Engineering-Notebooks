SARVAM SIMPLE CHATBOT

1. Open the .env file.
2. Replace PASTE_NEW_KEY_HERE with a NEW Sarvam API key.
   The key pasted into the chat should be revoked and not reused.
3. Open a terminal in this folder and run:

   python -m venv .venv

   Windows PowerShell:
   .\.venv\Scripts\Activate.ps1

   Install dependencies:
   pip install -r requirements.txt

   Start:
   python chatbot.py

Type exit or quit to stop the chatbot.
