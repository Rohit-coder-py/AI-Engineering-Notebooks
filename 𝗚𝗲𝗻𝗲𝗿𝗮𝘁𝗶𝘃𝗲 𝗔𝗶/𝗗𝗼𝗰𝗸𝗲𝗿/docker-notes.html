👋 Welcome to the workshop

Docker lets you package an app with everything it needs (Python, libraries, model files) into one portable box called an image. Anyone with Docker can run that image and get the exact same result — no "but it works on my machine!"

🛠 Role 1 — Developer

You finished an ML app. Package it, test it, and publish it to Docker Hub.

🤝 Role 2 — Teammate

Someone shared an image. Pull it, run it and open it on localhost — without their source code.

💡

Samples assume a Python + Streamlit ML app and Windows PowerShell. For Flask or FastAPI, only the start command and port change — the Lab tab generates the right files for you.

🧰 Setup: get your workshop ready

1 · Create a Docker Hub account

Go to hub.docker.com and sign up. Your username becomes your image namespace, e.g. rohitcoderpy/my-ml-project.

2 · Install Docker Desktop

Download it from docker.com, install, then open it and wait until the engine is running. On Windows it may ask to enable WSL 2 — accept.

3 · Check that Docker works

🐋

If docker info shows an error about the daemon, Docker Desktop is not running yet. Start it and wait for it to finish starting.

    📋 Command cheat sheet
    
    
    
    
    
    
    Safety reminders
    
    
      
      
    • Never put passwords, API keys, tokens or .env secrets in a public image.
      • 
      
    • A public image can be downloaded by anyone — review what you copy into it.
      • 
      
    • Keep model weights and preprocessing artifacts if the app loads them.
      • 
      
    • docker stop stops · docker rm deletes the container · docker image rm deletes the local image only.
      • 
      
    • Test before you push. If a push fails on the network, keep the image and retry — don't rebuild.
