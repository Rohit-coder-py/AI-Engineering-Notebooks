## 📌 About This Repository

<p>
This repo is my <b>public learning log</b> on the road to becoming an <b>AI Engineer</b> — not a course, not a tutorial, but a real, evolving record of what I study, build, break, and fix along the way.
</p>

<p>
It is <ins>intentionally unfinished</ins>. As I explore new libraries, frameworks, and topics, this repository keeps growing with them. Think of it less like a finished product and more like a <b>changelog of my skill-building</b>.
</p>

> 🔭 **Currently:** Month 5 is done — Python, math, ML, deep learning, NLP and Generative AI are behind me. I'm moving into **Month 6: capstone projects**, where the separate pieces (data → model → RAG / agents → API → container → deployment) finally get combined into fewer, bigger builds.

<details>
<summary><b>🧩 Agentic AI — the 5 LangGraph workflows I built</b></summary>

<br>

| Pattern | Build | What it proves |
|---|---|---|
| Sequential | **AI Study Material Generator** — research → explain → examples → MCQs | Chaining nodes where each one needs the previous output |
| Parallel | **AI Email Intelligence & Response Assistant** — intent, priority and reply agents run together | Fan-out, shared state and a custom reducer for merged writes |
| Conditional | **CareerMate AI** — a classifier node routes to the interview or resume guide, then answers from it (FAISS) | Branching on state with RAG-backed answers |
| Iterative | **AI Code Reviewer & Bug Fixer** — review, fix, re-check until done | Loops with a stopping condition instead of a straight line |
| Human-in-the-loop | **AI Research & Content Generator** — pauses for approval before continuing | Interrupts and resuming a graph with human input |

</details>

<details>
<summary><b>⚡ FastAPI, Docker & Deployment</b></summary>

- **FastAPI** — first app, path & query parameters, request bodies, exception handling, file uploads, auto-generated `/docs`
- **Serving models** — two projects where Streamlit is only the frontend and a FastAPI backend does the inference
- **Docker** — images vs containers, writing Dockerfiles, `.dockerignore`, passing API keys at runtime instead of baking them in
- **Deployment** — Streamlit Community Cloud, Render (API backend) and Docker Hub

</details>
