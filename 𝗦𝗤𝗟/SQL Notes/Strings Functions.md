| Function       | Purpose                                       |
| -------------- | --------------------------------------------- |
| `UPPER()`      | Convert text to uppercase                     |
| `LOWER()`      | Convert text to lowercase                     |
| `LENGTH()`     | Count the number of characters                |
| `TRIM()`       | Remove spaces from both ends                  |
| `LTRIM()`      | Remove spaces from the left                   |
| `RTRIM()`      | Remove spaces from the right                  |
| `CONCAT()`     | Join multiple strings together                |
| `\|\|`         | Concatenate strings (PostgreSQL operator)     |
| `SUBSTRING()`  | Extract part of a string                      |
| `LEFT()`       | Return characters from the left               |
| `RIGHT()`      | Return characters from the right              |
| `REPLACE()`    | Replace part of a string with another         |
| `POSITION()`   | Find the position of a substring              |
| `STRPOS()`     | Find the position of a substring (PostgreSQL) |
| `REVERSE()`    | Reverse the characters in a string            |
| `INITCAP()`    | Capitalize the first letter of each word      |
| `LPAD()`       | Pad the left side of a string                 |
| `RPAD()`       | Pad the right side of a string                |
| `SPLIT_PART()` | Split a string and return a specified part    |
| `REPEAT()`     | Repeat a string multiple times                |
