| **Keyword / Operation** | **Syntax**                                                                                                                | **Use Case**                                                |
| ----------------------- | ------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------- |
| **ADD COLUMN**          | `ALTER TABLE table_name ADD COLUMN column_name data_type;`                                                                | Add a new column to a table                                 |
| **DROP COLUMN**         | `ALTER TABLE table_name DROP COLUMN column_name;`                                                                         | Remove an existing column                                   |
| **RENAME COLUMN**       | `ALTER TABLE table_name RENAME COLUMN old_name TO new_name;`                                                              | Rename a column                                             |
| **ALTER COLUMN TYPE**   | `ALTER TABLE table_name ALTER COLUMN column_name TYPE new_data_type;`                                                     | Change a column's data type                                 |
| **SET DEFAULT**         | `ALTER TABLE table_name ALTER COLUMN column_name SET DEFAULT value;`                                                      | Set a default value for future inserts                      |
| **DROP DEFAULT**        | `ALTER TABLE table_name ALTER COLUMN column_name DROP DEFAULT;`                                                           | Remove a default value                                      |
| **SET NOT NULL**        | `ALTER TABLE table_name ALTER COLUMN column_name SET NOT NULL;`                                                           | Make a column mandatory (cannot contain `NULL`)             |
| **DROP NOT NULL**       | `ALTER TABLE table_name ALTER COLUMN column_name DROP NOT NULL;`                                                          | Allow `NULL` values again                                   |
| **ADD CONSTRAINT**      | `ALTER TABLE table_name ADD CONSTRAINT constraint_name constraint_definition;`                                            | Add constraints like `CHECK`, `UNIQUE`, `FOREIGN KEY`, etc. |
| **DROP CONSTRAINT**     | `ALTER TABLE table_name DROP CONSTRAINT constraint_name;`                                                                 | Remove an existing constraint                               |
| **RENAME TO**           | `ALTER TABLE table_name RENAME TO new_table_name;`                                                                        | Rename the table                                            |
| **ADD PRIMARY KEY**     | `ALTER TABLE table_name ADD PRIMARY KEY (column_name);`                                                                   | Add a primary key to an existing table                      |
| **ADD UNIQUE**          | `ALTER TABLE table_name ADD CONSTRAINT constraint_name UNIQUE (column_name);`                                             | Ensure all values in a column are unique                    |
| **ADD CHECK**           | `ALTER TABLE table_name ADD CONSTRAINT constraint_name CHECK (condition);`                                                | Restrict values using a condition                           |
| **ADD FOREIGN KEY**     | `ALTER TABLE table_name ADD CONSTRAINT constraint_name FOREIGN KEY (column_name) REFERENCES parent_table(parent_column);` | Create a foreign key relationship                           |
