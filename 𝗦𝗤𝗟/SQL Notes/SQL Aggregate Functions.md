| Function  | Purpose                  | Example                               |
| --------- | ------------------------ | ------------------------------------- |
| `COUNT()` | Counts rows              | `SELECT COUNT(*) FROM employees;`     |
| `SUM()`   | Adds numeric values      | `SELECT SUM(price) FROM flipkart_db;` |
| `AVG()`   | Calculates the average   | `SELECT AVG(price) FROM flipkart_db;` |
| `MIN()`   | Finds the smallest value | `SELECT MIN(price) FROM flipkart_db;` |
| `MAX()`   | Finds the largest value  | `SELECT MAX(price) FROM flipkart_db;` |
