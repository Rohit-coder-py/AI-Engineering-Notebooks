| Relationship Type  | Description                                                                      | Example                |
| ------------------ | -------------------------------------------------------------------------------- | ---------------------- |
| One-to-One (1:1)   | One record in Table A is related to only one record in Table B                   | Person ↔ Passport      |
| One-to-Many (1:N)  | One record in Table A can have many related records in Table B                   | Customer → Orders      |
| Many-to-One (N:1)  | Many records in Table A relate to one record in Table B (reverse of One-to-Many) | Employees → Department |
| Many-to-Many (M:N) | Many records in Table A relate to many records in Table B                        | Students ↔ Courses     |
